# Agent routes — select by intent

| Intent | Route | Result |
|---|---|---|
| Hivest portfolio workflow | Programme state → company manifest/index → Hivest workflow and gates | Governed portfolio run |
| New independent company/use case | `skills/standalone-company-analysis/SKILL.md` → new folder and graph first → research → three pages | Separate graph/output, no Hivest state changes |
| Resume standalone instance | Its manifest/index/graph → active node and questions | Continue within same entity boundary |
| Learning pilot | Learning README → canonical sheet → composition recipe | Learning artifact |
| Fund note | Fund index → strategic note template → renderer | Separate fund note |
| Contract/code change | Code map → owning schema/script | Bounded implementation |

Load only relevant files. At handoff retain entity, cutoff, active graph node, claims, contradictions, unknowns, checks and next action. A graph does not replace evidence or approval.
